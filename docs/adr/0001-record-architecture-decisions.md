# ADR 0001: Record Architecture Decisions

- Status: Accepted
- Date: 2026-11-27

## Context

The project has security-sensitive and clinical workflow decisions that must remain understandable over time.

## Decision

Use Architecture Decision Records in `docs/adr/` for significant technical/security decisions.

## Consequences

- Decisions become reviewable and auditable.
- Future changes must update/add ADRs when they alter core assumptions.
