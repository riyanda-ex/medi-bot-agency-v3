# Code of Conduct

## Our Standard

This project expects professional, respectful, and constructive collaboration.

Examples of expected behavior:

- Be respectful and considerate in language and actions.
- Give and accept constructive feedback.
- Focus on what is best for users, patients' data safety, and the project.
- Handle sensitive security and clinical topics responsibly.

Unacceptable behavior includes:

- Harassment, discrimination, insults, or personal attacks.
- Publishing private information, secrets, or patient data.
- Intimidation, trolling, or deliberately disruptive conduct.
- Encouraging unsafe clinical use, insecure deployment, or policy bypasses.

## Scope

This Code of Conduct applies in project spaces, issues, pull requests, discussions, and other interactions representing the project.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this Code of Conduct. Serious or repeated violations may result in temporary or permanent bans from project participation.

## Reporting

For conduct concerns, contact the repository owner via GitHub: [@riyanda-ex](https://github.com/riyanda-ex). For security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) and do not open a public issue.
