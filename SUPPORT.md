# Support

## Getting Help

- **Documentation**: start with [README.md](README.md) / [README.id.md](README.id.md), [docs/](docs/), [TESTING.md](TESTING.md), and [docs/PRODUCTION-CHECKLIST.md](docs/PRODUCTION-CHECKLIST.md).
- **Security & operations**: [SECURITY.md](SECURITY.md), [docs/THREAT-MODEL.md](docs/THREAT-MODEL.md), [docs/PRIVACY-DATA-HANDLING.md](docs/PRIVACY-DATA-HANDLING.md), [docs/INCIDENT-RESPONSE.md](docs/INCIDENT-RESPONSE.md), and [docs/adr/](docs/adr/).
- **Bug reports**: open a non-security issue using the bug report template. Include your queue mode (`sync` or `redis`) and the output of `npm run queue:check` for queue issues; the check supports both modes.
- **Security vulnerabilities**: **do not** open a public issue. Follow [SECURITY.md](SECURITY.md).

## Project Status

This repository is a proprietary clinical operations foundation/prototype. It is **not a certified medical device** and should not be used with real patient data before clinical validation, legal review, security assessment, and proper production controls.

## Response Expectations

- Best-effort maintainer response for authorized collaborators.
- Security reports: see response targets in [SECURITY.md](SECURITY.md).
- Feature requests may be declined if they conflict with safety, privacy, or licensing constraints.
