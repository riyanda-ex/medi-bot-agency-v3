# Support

## Getting Help

- **Documentation**: start with [README.md](README.md), [docs/](docs/), [TESTING.md](TESTING.md), and [docs/PRODUCTION-CHECKLIST.md](docs/PRODUCTION-CHECKLIST.md).
- **Bug reports**: open a non-security issue using the bug report template.
- **Security vulnerabilities**: **do not** open a public issue. Follow [SECURITY.md](SECURITY.md).

## Project Status

This repository is a proprietary clinical operations foundation/prototype. It is **not a certified medical device** and should not be used with real patient data before clinical validation, legal review, security assessment, and proper production controls.

## Response Expectations

- Best-effort maintainer response for authorized collaborators.
- Security reports: see response targets in [SECURITY.md](SECURITY.md).
- Feature requests may be declined if they conflict with safety, privacy, or licensing constraints.
